# 작업 세션 이름

작업할 Jira 이슈가 정해지면, 세션 이름을 바꾸는 도구가 있는 환경에서는 현재 이름 앞에 Jira 키를 붙인다. `<Jira 키> <기존 작업명>` 형식을 쓰고, 같은 키로 시작하면 유지한다. 담당 이슈가 바뀌면 앞의 키를 바꾼다. 이름 변경 도구가 없으면 이 단계를 생략한다.

Jira가 없는 업무는 작업명을 그대로 쓴다. `REQ-001` 같은 임시 번호를 Jira 키로 만들지 않는다. 세션 이름은 검색에 쓰고, 세션을 연결할 때는 도구 이름과 실제 세션 ID를 함께 사용한다.
