# 업무 메시지 작성

받는 사람이 내용과 다음 행동을 이해할 수 있는 메시지를 작성한다.

1. 요청이 초안 작성, 문장 수정, 내용 검토 중 무엇인지 구분한다. 원문에서 수신자와 목적을 알 수 있으면 바로 진행하고, 답에 따라 요청 내용이 달라지는 정보만 질문한다.
2. [공통 기준](../work-agent-writing/common.md)을 읽는다. PR 리뷰 댓글이면 [리뷰 댓글 기준](references/pr-comments.md)도 읽는다. 메시지에 필요한 사실과 요청이 자료에서 확인되면 초안을 작성한다. 빠진 사실은 확인할 내용으로 남긴다.
3. 초안과 원문을 공통 기준의 **원문 대조**로 비교한다. 의미가 달라진 부분을 고치고, 받는 사람이 해야 할 행동을 본문에서 찾을 수 있으면 완료한다. 단순 알림에는 행동을 억지로 추가하지 않는다.

## 출력

- **초안·문장 수정:** 바로 사용할 본문만 출력한다. 사용자가 여러 대안을 요청했다면 대안만 구분한다.
- **내용 검토:** 본문 뒤에 실제로 확인이 필요한 내용만 덧붙인다. 기한·대상·요청이 필요한데 빠졌는지 확인한다. 빈 점검 항목은 출력하지 않는다.
- **근거 부족:** 확인되지 않은 내용을 합의나 결함으로 바꾸지 않고 질문 또는 확인할 사항으로 남긴다.

초안 작성은 전송과 별개다. 외부 전송은 사용자가 맡긴 범위에서 수행한다.
