# 짧은 현황 공유

독자가 이미 아는 배경보다 진행한 일, 다음 계획과 전파할 내용을 먼저 쓴다.

- 데일리는 최근 진행한 일과 오늘 계획을 중심으로 쓴다. 문제·도움 요청·결정 안건은 공유할 내용이 있을 때만 넣는다.
- 주간 공유는 이슈별 결과와 남은 일을 묶는다. 계획과 실제 수행을 구분하고, 작업 시간은 실제 등록된 값만 사용한다.
- 사용자가 요청한 분량에 맞는 문단이나 목록을 사용한다. 항목이 두 개라면 두 개만으로 끝낼 수 있다.

완료 기준: 전달할 사실과 다음 계획이 원자료와 맞고, 빈 항목이나 추정한 성과가 없는가.
