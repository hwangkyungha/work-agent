# 계획 문서

현재 상태와 목표를 설명하고, 이번에 할 일과 범위 밖의 일을 구분한다.

- 작업 순서는 선행 조건과 확인 가능한 완료 기준으로 설명한다.
- 정해진 결정에는 근거와 날짜를 남기고, 새 선택에는 대안과 판단 기준을 적는다.
- 상위 결정에 따라 자동으로 정해지는 세부 사항은 별도 안건으로 부풀리지 않는다.
- 문서를 갱신할 때는 현재 상태를 본문에 반영한다. 이전 결정을 알아야 잘못된 행동을 피할 수 있는 경우에는 대체 사유도 남긴다.

완료 기준: 범위, 선행 조건, 실행 순서와 완료 기준을 알고 착수할 수 있는가.
