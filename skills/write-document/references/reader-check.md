# 배경 없는 독자의 검토

별도 독자에게 문서 본문과 독자가 누구인지만 제공한다. 작성 대화와 원자료, 작성자의 의도는 제공하지 않는다. 독자에게 다음 질문의 답과 근거 문장을 요청한다.

1. 이 문서에서 요청하는 판단이나 행동은 무엇인가.
2. 현재 상태와 해결하려는 문제는 무엇인가.
3. 확인한 사실, 제안과 남은 결정은 구분되는가.
4. 선택의 근거와 남는 비용·위험은 무엇인가.
5. 뜻을 추측하거나 두 번 읽어야 하는 문장은 무엇인가.

해당 문서에 필요한 질문에 답할 수 없거나, 모호한 문장이 판단을 막으면 수정한다. 수정 후 같은 방식으로 한 번 더 확인한다. 두 번 수정해도 남는 문제는 사용자에게 구체적인 문장과 함께 알린다.

별도 독자를 호출할 수 없는 환경에서는 혼자 읽은 결과를 독립 검토로 표시하지 않는다. 본문과 함께 독자 검토를 수행하지 못했다는 사실을 짧게 남긴다.
